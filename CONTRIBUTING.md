# Contributing to This Project

First off, thank you for taking the time to contribute! We welcome contributions from everyone, whether you are fixing a bug, updating documentation, or proposing a major new feature.

By participating in this project, you agree to abide by our Code of Conduct and respect our project governance.

---

## How Can I Contribute?

### 1. Reporting Bugs & Suggesting Minor Improvements
* Check the existing issues to ensure it hasn't already been reported.
* Open a new issue with a clear title and description.
* Provide reproducible steps, error logs, or environment details if reporting a bug.

### 2. Proposing Major Features (RFC Process)
For large features, architectural changes, or breaking updates, we use a formal **Request for Comments (RFC)** process. 
* Open an issue using our **Feature Proposal (RFC)** template.
* Engage with the community and Project Leads during the discussion period.
* Read our [GOVERNANCE.md](GOVERNANCE.md) to understand how proposals are reviewed and approved.

### 3. Submitting Pull Requests (PRs)
* Fork the repository and create your branch from `main`.
* Ensure your code adheres to the project's existing code style and formatting guidelines.
* Write clear, concise commit messages.
* Open your PR against the `main` branch. 
* Routine PRs require a review from at least one Project Lead to be merged.

---

## Code of Conduct

We are committed to providing a welcoming, inclusive, and harassment-free experience for everyone. Please review and follow our standard Code of Conduct in all community interactions.

## Community & Governance

This project is independently led by two co-maintainers. To learn more about how decisions are made, how ties are broken, or how to become a maintainer yourself, please check out our [GOVERNANCE.md](GOVERNANCE.md).
